## Revue hebdomadaire

La revue doit confirmer que le milestone actif n’a pas dérivé vers “tous les modèles” ou “tous les flows”. Elle doit vérifier la qualité des preuves plutôt que le volume de pages livrées, rapprocher le paiement fournisseur de la ligne `credits_ledger`, inspecter les états d’échec et de récupération, puis enregistrer une décision **keep / change / pause / stop** avec un propriétaire et une condition de réexamen.

La décision de cette revue est : **keep** le milestone Developer Platform, **keep** le compte, le ledger, Mobile Money et la génération vérifiée, **block** toute transaction de smoke tant que le redéploiement API n’est pas confirmé, puis exécuter clé → recharge → playground → appel API. Le canvas grand public, les agents autonomes non bornés, l’expansion Canva et le SDK restent en pause.

## Prochaine action minimale

Conserver les migrations versionnées comme seule voie opérateur et garder les gates locaux verts. Prochaine action : redéployer la correction des Server Routes, relancer `pnpm smoke:developer` en mode sûr sur la production, puis seulement ouvrir une session dédiée pour la clé, la recharge exacte de 1 USD, le playground et une génération explicitement confirmée.
